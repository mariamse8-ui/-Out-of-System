# -Out-of-System
في عام 2095، تعيش ليان في عالم تراجعت فيه المشاعر بسبب اعتماد البشر على أنظمة تحميهم من الألم. تدخل تجربة عصبية تحاكي الإسكندرية عام 2026 لاكتشاف سر اختفاء المشاعر. وبينما تخوض مواقف تختبر تعاطفها واختياراتها، تكتشف أن المشاعر لا تُزرع بالتكنولوجيا، بل تستيقظ بالتجربة الإنسانية والقدرة على الاختيار والتضحية.
